script.json alone does not list call sites; the closure was resolved by scanning the
executable segment for the binary's virtual-call idiom. Idiom learned from sampled
BLR sites (r7f_blr_sample):
  direct virtual:   ldr xK,[xR] ; ldr xM,[xK,#off] ; [ldr xT,[xK,#off+8] ;] blr xM
  low-slot variant: … ldp xM,xT,[xK,#off] ; blr xM
  interface path:   ldrsw x9,[x10] ; add x8,x8,x9,lsl #4 ; add x0,x8,#0x138 ; ldp …
Il2CppClass layout (dumper il2cpp.h, metadata v31): vtable[] at offset 0x138,
VirtualInvokeData = 16 B {methodPtr, method} -> slot S lives at klass + 0x138 + S*16,
and LDR imm12 = (0x138 + S*16)/8 = 39 + 2S. Interface dispatch computes offsets as
N*16 + 0x138 (lsl #4 + add #0x138) — independently confirming base 0x138 / stride 16.
