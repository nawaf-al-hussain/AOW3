## What the collection preserves of 6.5.22

1. **Java layer** (jadx): complete decompile of the APK's DEX code. Third-party dominated;
   game-specific surface: `com.geargames.aow.logger.*` (BuildConfig, ILogger, NativeLogger,
   LoggerSendMessage, LoggerDummy), `com.geargames.aow.nativeplugins.*` (GGNativeUtils,
   ANRWatchDog*, PushUtils, AdvertisingInfoReader, AppSetIdInfoReader, ActivityChangeDetector,
   AppAutoExitOnPauseManager, AndroidApplicationExitInfo*), `com.geargames.aow.resources.R`,
   `com.geargames.aow.R`.
2. **IL2CPP name lists** (curated): 1,247 method names in 9 categories; 25,017 type names;
   9,552 game types with namespaces (`game_types.json`).
3. **GAI command system** (753 names): full command/Component/STSerializer/STDeserializer families
   + `GAI_COMMAND_*` constant names (146).
4. **Metadata-derived groupings** (`game_identifiers.json`, `namespaces.json`): grouped identifier
   lists for NetworkMessages / Units / Buildings / Combat / AI (the producing session's categories).
5. **Analysis documents**: 14 unique files (×3 copies) + `aow3_documentation` superset (23 md +
   diagrams), written against this version.

## Version-specific evidence handling rule

No numeric value from the 6.5.22 material may be imported into 6.9.18-scoped notes without
independent 6.9.18 verification. The only values the collection carries are *names* (identifiers),
which is why name-level cross-version tables are the only imports.
